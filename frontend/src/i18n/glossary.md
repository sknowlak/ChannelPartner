# Translation glossary (English → हिन्दी / বাংলা)

Use these exact terms everywhere - partner app, builder portal, admin portal,
mobile app and notification templates - so the same concept never has two
names. Professional, respectful register (आप / আপনি forms). Translate meaning,
not word for word. When a term below is marked *(keep)*, it is left in English
or transliterated because users know it that way.

Never translate: product names (Leadrat), customer/partner/builder/project
names, IDs (REG-…, BOOK-…), phone numbers, emails, API keys, URLs, field keys,
JSON keys, HTTP methods, status codes, `{{placeholders}}` and anything a user
typed.

Bengali counters: use "{{count}}টি" for counts of things. Hindi plural nouns
often match the singular (लीड, रिकॉर्ड) - still provide both `_one` and
`_other` keys.
